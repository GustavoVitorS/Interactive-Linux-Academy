Learn with the manuals that Linux users actually rely on.

The course summarizes concepts for learning, while these links take you to primary documentation for deeper study and verification.

GNU
GNU Coreutils Manual

Primary manual for foundational file and system utilities such as ls, cp, mv, rm, pwd and chmod.

Linux interfaces and a curated collection of manual pages, organized by traditional man sections.

Reference for conventional purposes and placement of directories such as /etc, /home, /usr and /var.
